# BYD Probe

Діагностичний застосунок для DiLink (BYD Seal 06 GT). Він показує, які дані
автомобіля (насамперед температуру) можна прочитати через внутрішній API
`android.hardware.bydauto`. Застосунок **нічого не змінює** в машині: викликає
лише методи читання `get*`/`is*` і ніколи не викликає `set*`.

## Як зібрати APK (без Android Studio)

1. Зареєструйтеся на github.com.
2. Створіть новий репозиторій (можна приватний) і завантажте в нього **вміст**
   цього архіву (Add file → Upload files). Важливо, щоб папка `.github` теж
   потрапила в репозиторій. Якщо браузер її не завантажує, створіть файл
   `.github/workflows/build.yml` вручну (Add file → Create new file) і
   скопіюйте туди його вміст.
3. Відкрийте вкладку **Actions**. Збірка запуститься сама й триватиме 3–5 хвилин.
4. Коли з'явиться зелена галочка, відкрийте запуск і внизу, в розділі
   **Artifacts**, завантажте `byd-probe-apk` (це zip, всередині `app-debug.apk`).

## Як запустити в машині

1. Скопіюйте `app-debug.apk` на флешку так само, як ставили APK раніше.
2. Встановіть і відкрийте **BYD Probe**.
3. Якщо система попросить доступ до файлів, дозвольте.
4. Натисніть **Start / Почати** і зачекайте, поки з'явиться `=== DONE ===`.
5. Звіт збережеться у файл `byd_probe.txt` у папці Download і в корені
   флешки, якщо вона вставлена. Надішліть цей файл (або фото розділу
   `TEMPERATURE SUMMARY` та кінця звіту) у чат.

За цим звітом буде видно, чи можна зробити віджет із температурою і які
саме методи для цього використати.
