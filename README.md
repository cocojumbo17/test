# BYD Temp

Показує температуру в салоні та на вулиці для BYD Seal 06 GT (DiLink 5.0)
у плаваючому віконці поверх екрана і в шторці сповіщень.

Дані читаються з внутрішнього API BYD (`get(1000, AC_TEMP_INSIDE / AC_TEMP_OUT)`)
від імені користувача `shell` через ADB самої машини (127.0.0.1:5555).
Застосунок лише читає дані й нічого в машині не змінює.

## Збірка

GitHub Actions збирає `BydTemp-v<версія>-debug.apk` при кожному push
(вкладка Actions → останній запуск → Artifacts).
Версія задається у `app/build.gradle` (`appVersionName`).

## Перший запуск

1. Встановити APK і відкрити застосунок.
2. Якщо з'явиться «Дозволити налагодження по USB?», поставити «Завжди дозволяти».
3. Вимкнути для застосунку обмеження автозапуску в налаштуваннях DiLink.

## Налаштування

- показати/сховати віконце, повернути його в центр екрана;
- прозорість фону віконця;
- розмір шрифту віконця (14–40);
- колір тексту;
- сніжинка біля вуличної температури нижче +5°;
- системні сповіщення про зміну температури (за замовчуванням вимкнені; фонове сповіщення «BYD Temp працює у фоні» лишається завжди, бо його вимагає Android).
